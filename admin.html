Admin sign in

Set ADMIN_EMAIL and ADMIN_PASSWORD in environment variables (Vercel project settings for production, or .env when using npm start). Use a strong password in production. After signing in, keep the same site origin (localhost vs 127.0.0.1) for the whole session.

Submissions use Vercel KV (Redis) when KV_REST_API_URL / KV_REST_API_TOKEN are set; otherwise locally they use .data/submissions.sqlite. Configure the same KV as user accounts for hosted deployments.
